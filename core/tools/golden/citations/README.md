# Citations golden stand

Pins the C++ port of Agora's **citation pipeline** — source records, their normalization and
merge rules, the private-marker scrubber, the copy/encode/decode surfaces, and the provider
citation projections:

| Kotlin source | What it owns |
| --- | --- |
| `model/Citation.kt` (`CitationAnchor`, `CitationRecord`, `CitationPolicy`) | record model, `create`/`normalize`/`merge`/`deduplicate`, anchor normalization, `stripPrivateMarkers` (5 private regexes), `copyText` markdown rendering, kotlinx `encode`/`decode`, `safeHttpUrl` |
| `api/anthropic/AnthropicCitationProjection.kt` | tree decode of the private `AnthropicCitation` JSON and its dispatch to `CitationPolicy.create` |
| `api/gemini/GeminiCitationProjection.kt` | grounding-chunk/support walk, UTF-8 byte-range → UTF-16 anchor mapping, `toGeminiAnchor` |
| JDK 26 `java.net.URI` | the parse / getters / `toString` / `toASCIIString` / `normalize` surface `safeHttpUrl` is defined in terms of (`uri` mode) |

The traces are produced by the **real Kotlin sources compiled straight from the app tree**
(`run_golden.sh` lists them); leaf stubs replace Android-only loaders and compile-only
annotations only (`androidx.compose.runtime.Immutable`, `com.mikepenz.markdown.model.State`) —
no stub participates in a trace. The C++ port must reproduce every trace byte for byte
(`core/tests/citations_parity_test.cpp`).

## Usage

```bash
KOTLINC=.../kotlinc KOTLINX_JARS=.../json.jar:.../core.jar ./run_golden.sh            # verify
KOTLINC=... KOTLINX_JARS=... ./run_golden.sh --freeze                                 # regenerate
```

Requirements match the other stands (kotlinc with the kotlinx-serialization compiler plugin
and jars). 228 scenarios / traces as of the freeze.

Scenario JSON is regenerated by `gen_policy.py`, `gen_projections.py` and `gen_urls.py` (run
from this directory); the scripts are deterministic and the traces regenerate bit-identically
with the JDK 26 / kotlinc pair noted in the driver header.

## Modes

Every scenario carries `name` (must equal the file stem) and `mode`:

| mode | exercised API | inputs |
| --- | --- | --- |
| `create` | `CitationPolicy.create` | `provider`, `kind`, `title`, `url`, `fileName`, `location`, `providerSourceId`, `excerpt`, `anchors[]`, `answerText?` |
| `normalize` | `CitationPolicy.normalize` | top-level record fields, `answerText?` |
| `merge` | `CitationPolicy.merge` | top-level record + `incoming` (mismatched `sourceId` throws) |
| `deduplicate` | `CitationPolicy.deduplicate` | `records[]`, `answerText?` |
| `strip` | `CitationPolicy.stripPrivateMarkers` | `text` |
| `copy` | `CitationPolicy.copyText` | `text`, `records[]` |
| `encode` | `CitationPolicy.encode` | top-level record fields |
| `decode` | `CitationPolicy.decode` | `raw` (kotlinx `decodeFromString<CitationRecord>`), `answerText?` |
| `safeUrl` | `CitationPolicy.safeHttpUrl` | `url` (nullable) |
| `matchTitle` | `matchesCitationTitle` | `records[]`, `query` |
| `anthropicCitation` | `toAnthropicCitationRecord` | `citation` (JSON text), `answerStartIndex`, `text` |
| `geminiCitations` | `toGeminiCitations` | `metadata` (JSON text), `text` |
| `uri` | `java.net.URI(String)` + getters + `toASCIIString` + `normalize` | `cases[]` (raw strings) |
| `safeUrlFuzz` | `safeHttpUrl` over hostile `cases[]` | each case is the raw string |

Record objects (top-level, `incoming`, `records[]`) use the Kotlin property names
(`version`, `sourceId`, `provider`, `kind`, `title`, `url`, `fileName`, `location`,
`providerSourceId`, `excerpt`, `anchors[{startIndex, endIndex, citedText}]`), with the
kotlinx-by-default semantics: absent optional scalars mean null, absent `version` means 1.

## Trace format

Pipe-separated lines, header `name|<name>` and `mode|<mode>`; a trailing
`error|<ExceptionSimpleName>` appears only when the API under test throws (the exception
class alone is the contract — `merge`'s `require` maps to `IllegalArgumentException`, the URI
constructor to `URISyntaxException`, JSON parse failures to `JsonDecodingException`).

Escaping in field position: `\` → `\\`, `|` → `\p`, `;` → `\s`, `"` → `\q`, newline/CR/tab →
`\n`/`\r`/`\t`. A rendered record is

```
v=<version>;sourceId="…";provider="…";kind="…";title="…";url=<quoted-or-null>;fileName=…
;location=…;providerSourceId=…;excerpt=…;anchors=[{<start>,<end>,"<text>"},…]
```

Key lines (C++ parity test mirrors them exactly):

- `create`/`normalize`/`merge`/`decode`/`record` (anthropic): one record rendering or `null`
- `deduplicate`/`geminiCitations`: `count|<n>` + n × `record|<i>|<rendering>`
- `strip`/`copy`/`encode`: the result string, quoted
- `safeUrl`: the safe URL, quoted-or-`null`; `safeUrlFuzz`: `case|<i>|<q(raw)>|<q-or-null>`
- `matchTitle`: `matchTitle|0|1`
- `anthropicCitation`: `parse|throw|JsonDecodingException`, else `record|<rendering|null>`
- `geminiCitations`: `parse|throw|JsonDecodingException`, or `metadata|notObject`, or the
  `count|`/`record|` pair above
- `uri`: per case `case|<i>|<q(raw)>` then either `parse|throw|URISyntaxException` or
  `parse|scheme=…|userInfo=…|host=…|port=…|path=…|query=…|fragment=…|authority=…|opaque=0|1|absolute=0|1`
  followed by `ascii|<q>`, `normalized|<q>`, `normalizedAscii|<q>`. `scheme`/`host`/`port` are
  the raw `getScheme`/`getHost`/`getPort` values; `userInfo`/`path`/`query`/`fragment`/
  `authority` go through the JDK's decoding getters (`getUserInfo` etc.).

## Boundaries (documented scope, not stubs)

- **Chat-row adapters** (`toMessageSegment`, `toCitationRecord`, `citationRecords`,
  `copyTextWithCitations`) compile in the stand but no scenario exercises them; they belong
  to the chat-model slice and are not part of this port.
- **ASCII-only case folding** in the C++ port (lowercasing, `contains(ignoreCase)`,
  `replaceFirstChar` uppercasing, the private marker regexes under `IGNORE_CASE`). Kotlin's
  Unicode case equivalence (U+0131 `ı`≈`i`, U+212A `K`≈`k`, U+017F `ſ`≈`s`, …) is out of
  scope, consistent with the stream stand.
- **NFC normalization inside `java.net.URI.encode()`** is not ported: the JDK normalizes each
  percent-encoded run through `Normalizer.normalize(NFC)`; every pinned input (and every
  plausible model-emitted URL) is already NFC precomposed text.
- **Lone/unpaired surrogates** cannot be represented in the port (input travels as UTF-8);
  the corpus excludes them. `GeminiCitationProjection.utf8BoundaryMap`'s surrogate-rejection
  branches are therefore unreachable and folded into the UTF-8 validity of the input.
- **`String.toIntOrNull`** (tree-decoded `Int?` fields) is pinned ASCII-only: optional sign +
  `0-9` + Int range. The JVM would additionally accept other Unicode digits via
  `Character.digit`; no pinned scenario uses them.
- **kotlinx quirks pinned here deliberately**: streaming `decodeFromString` accepts quoted
  ints (`"1"`) and rejects `1.5`/escaped digits; unknown keys are skipped; duplicate keys are
  last-wins; trailing content is an error; tree decoding takes `Int?` through
  `content.toIntOrNull()` (so `1.5` fails), requires JSON strings for `String?` fields, and
  `JsonNull` surfaces as the string `"null"` through `stringContent`.
- **URI port scope**: only the surface above is ported 1:1 from JDK 26; the JVM NPE paths
  (unpaired surrogates in `encode`) and `Normalizer` are not representable. `toString()`
  returns the original input string for parsed URIs.
