# 关于

打开**设置 → 关于**可查看已安装版本、构建信息、项目链接、开源许可、更新状态和可选反馈表单。

## 更新检查

启用自动更新检查时，Agora 在应用启动时检查新版本，最多每天一次。检查只获取发布元数据；安装仍需用户明确操作，不同分发渠道的版本可能不同。

## 反馈

评分表单只会把你主动填写的评分、姓名、邮箱和评论发送到 `https://newoether.com/api/rating`。

发生意外崩溃后，Agora 会在本地保留一份待处理报告，并在下次启动时询问是否发送；没有明确操作就不会上传。报告包含堆栈、应用/Android 版本、设备厂商/型号、时间戳和有界诊断事件，不包含对话文本、凭据或设备标识符。

数据处理和网络去向详见[隐私与安全](privacy.md)。
