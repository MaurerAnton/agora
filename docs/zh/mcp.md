# 模型上下文协议（MCP）

Agora 可以连接远程 MCP 服务器，并把服务器提供的工具交给支持工具调用的聊天模型。

## 添加服务器

1. 打开**设置 → MCP**。
2. 点击**添加 MCP 服务器**。
3. 选择 **Streamable HTTP** 或 **SSE**。
4. 输入显示名称，以及以 http:// 或 https:// 开头的服务器 URL。
5. 只添加服务器必需的自定义 HTTP 请求头，然后保存。

Streamable HTTP 是当前传输方式；SSE 用于兼容旧版 MCP 服务器。

自定义请求头值使用与 API Key 相同的机密设置存储：通常由 Android Keystore AES-GCM 封装，但旧值或加密失败时可能为明文。其中可能包含授权令牌，请保护设备和导出文件，并且不要添加服务器不需要的请求头。

## 连接与工具发现

已启用的服务器会在后台连接，状态显示为**空闲**、**正在连接**、**已连接**或**连接错误**。可以在服务器菜单或编辑页中选择**重新连接**来重试发现。

连接成功后，Agora 会列出服务器的工具。新发现的工具默认启用；在服务器编辑页中可以逐项关闭。关闭整个服务器会使其全部工具不可用，但不会删除配置。

模型会收到三个固定 MCP 入口。`mcp_list_servers` 列出已启用服务器的稳定 ID、本地连接状态与可用工具数，包括暂不可用或没有工具的服务器；它不会发起连接或刷新，也不会返回端点 URL、请求头或异常详情。`mcp_search_tools` 搜索可用工具并返回完整输入结构，`mcp_call_tool` 使用搜索得到的精确 `tool_id` 和 `arguments` 对象执行调用，具体参数约束由 MCP 服务器校验。

默认搜索所有服务器，无需每次先列目录。搜索支持关键词、空查询浏览、精确 `server_id` 筛选及分页。无效或已禁用的服务器 ID 返回 `invalid_server`；已启用但当前未连接的服务器返回 `server_unavailable`；有效且已连接的服务器没有匹配工具时，正常返回空页。指定服务器后不会自动扩大为全局搜索。只有已连接且启用的工具可以被搜索和调用。

列目录、搜索与调用复用 Agora 的标准工具流程，结果保存在对话历史中。修改服务器或工具清单不会改写这三个入口定义，也不会重算此前的结果，从而保留提示缓存前缀的复用条件。新增列表入口时，前缀会改变一次；实际是否命中仍受提供商、模型、系统提示词、上下文窗口与缓存有效期影响。

## 编辑或删除服务器

点击服务器可以编辑传输方式、名称、URL、自定义请求头、连接状态和已启用工具。服务器右侧菜单可用于重新连接或删除。

删除服务器会移除其配置并停用对应工具，但不会删除已有的对话历史。

## 安全

MCP 工具可能在外部系统产生副作用。请只连接可信服务器、检查工具清单，并授予尽可能小的凭据范围。离开可信局域网时优先使用 HTTPS。

## 故障排查

### 连接错误

- 确认 Android 设备可以访问该 URL。
- 确认所选传输方式与服务器匹配。
- 检查认证请求头与服务器日志。
- 修改配置后使用**重新连接**。

### 没有显示工具

- 确认服务器已启用且状态为**已连接**。
- 重新连接以刷新工具发现。
- 打开编辑页，确认具体工具没有被关闭。

### 模型没有获得某个工具

当前模型与提供商必须支持工具调用，同时服务器和该工具本身都必须处于启用状态。
