# 远程 Shell

打开**设置 → Shell 设备**配置供代理工具使用的 Conch 或 SSH 设备。为每台设备填写唯一名称，点击保存后才创建。名称忽略首尾空白和大小写；`Local Sandbox` 为本地沙盒保留，不能用于远程设备。重名时无法保存，未保存就离开新增编辑器不会创建设备。

## Conch

配置服务器 URL、可选 API Key 和命令确认策略。有 API Key 时，Agora 获取服务器签名公钥，派生临时共享密钥，并发送经过认证的 AES-GCM 请求。空 Key 时应用层载荷是明文 JSON，机密性只依赖 HTTPS。

前台命令会创建持久任务并等待有限时间。等待超时不会杀死或重放命令，而是返回 `job_id`；之后可查询、等待、停止和确认删除。Conch 还支持远程读取、写入、编辑、glob、grep 与图像查看。

## SSH 与确认

配置主机、端口和用户名，然后选择密码认证，或选择**私钥**并点击**导入私钥**，导入不超过 256 KiB 的文件。加密私钥还需填写私钥口令。使用**验证并固定主机密钥**核对服务器指纹，点击**保存**才会存储设备和凭据；固定后，后续连接的主机密钥必须与之匹配。凭据在设备上加密存储。结构化设置导出不包含密码、私钥及私钥口令；原生 `.agora` 备份仅在明确选择包含密钥时才包含这些内容。直接 SSH 不受共享 HTTP 代理控制。命令可要求确认，或按服务器设为始终允许；远程账户权限决定模型可执行的操作。
